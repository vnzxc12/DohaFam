## 🚀 How to Run Locally

```bash
# 1. Install dependencies
npm install

# 2. Start server
npm start
```
- Open `http://localhost:3000` on your computer.
- Open `http://<your-lan-ip>:3000` on your phone (same Wi-Fi).

---

## ☁️ Deploying to Vercel

1. Import this repository into [Vercel](https://vercel.com/new).
2. Set Environment Variables in Vercel Project Settings:
   - `SUPABASE_URL`: `https://nkctcwwbgqrqmfcqfksa.supabase.co`
   - `SUPABASE_ANON_KEY`: *(your Supabase anon key)*
3. Click **Deploy**!

---

## 🗄️ Supabase Setup
Run the SQL queries in [`schema.sql`](./schema.sql) in your [Supabase SQL Editor](https://supabase.com/dashboard/project/nkctcwwbgqrqmfcqfksa/sql) to set up the `wishlist_members` table and seed the initial members.
